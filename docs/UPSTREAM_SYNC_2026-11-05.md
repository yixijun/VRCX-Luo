## 本轮检查与修复

- 商城搜索与模型弹窗共用购买确认逻辑：确认后再次检查账号与余额，同步锁阻止重复提交，取消、失败或组件卸载后释放状态。
- 余额、所有权和购买历史绑定发起请求时的账号生命周期。切换账号、切走后再切回、登出后重新登录，都会使旧请求失效；较早的余额请求不能覆盖较新的请求结果。
- 账号或视图切换时清理余额和购买缓存；购买历史关闭或切换账号时清理交易及筛选，旧请求不能覆盖新结果或提前结束新请求的加载状态。
- 免费物品领取固定本批次的账号及商品列表，逐项传递确认账号；切换账号或组件卸载后停止后续领取，旧批次不刷新或关闭新账号的弹窗。
- 商城首开时加载余额，余额加载失败不阻止货架展示；旧余额 API 委托到受账号保护的商城入口。WebSocket 余额事件只在主账号视图更新当前余额。
- 购买、免费领取、余额和购买历史目前仅支持主账号视图；非主账号视图显示提示并禁用购买。未改写 `accountHub`、`dbVars` 或副账号会话路由，遵循 ADR-0004 的范围约束。
- 补充账号切换、迟到响应、重复操作、取消、失败重试、卸载、免费领取批次及旧余额入口的回归测试；修复媒体测试对新增商城依赖的隔离。
