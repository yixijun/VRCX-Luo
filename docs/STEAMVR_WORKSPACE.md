# SteamVR 工作区

## 进入方式

登录 VRCX-Luo，启用 SteamVR 集成。在 SteamVR 底部菜单打开 VRCX-Luo，然后选择 **VR 工作区 · 全部功能**。

工作区拥有独立的功能大厅、分类导航、返回、详情关闭和输入工具。现有的控制/设备、好友/邀请快捷页保留，可随时通过“快捷控制”返回。

首页按“当前房间与社交入口 → 六个常用入口 → 全部功能分类”组织，点击分类后再展示该分类的功能。左侧保留简洁的分类导航和账户区域，返回固定在顶部；工作区及快捷控制页使用统一的青蓝强调色和大尺寸按钮。记录卡片缩减冗余留白，操作区域与内容分开显示。

## 功能覆盖

| 分组 | 已接入的功能 |
| --- | --- |
| 动态与房间 | 活动动态、好友房间、游戏日志、当前玩家 |
| 发现 | 用户/世界/模型/群组搜索、我的模型 |
| 社交与收藏 | 好友列表、好友日志、玩家管理、通知、星标好友、世界/模型收藏 |
| 图表与记录 | 房间活动、共同好友、热门世界、双人关系、关系时间线 |
| 工具与设置 | 工具页及其弹窗、图库、截图信息、全部设置分类 |
| 自定义面板 | 按当前保存的面板定义生成入口；创建、编辑可从“账户与管理”的导航菜单进入 |
| 好友与群组 | 完整侧栏及其搜索、分组、房间、用户/群组详情操作 |
| 账户与管理 | 原账户菜单、添加账户、退出登录、更新、主题、导航管理；账户视图切换器独立保留 |
| 文件 | VR 内选择文件/目录、浏览器上传（含多选）、Windows CEF 导出保存位置及文件名选择 |

普通内容页入口从实际路由目录生成，新增普通页面会自动出现；动态面板使用其真实 ID。业务页面和详情组件在 VR 布局中复用，以保持设置、权限、确认流程和数据源一致。此版本重做导航、列表卡片与交互尺寸，未为每一个详情页面另建一份业务实现。

使用共用表格组件的页面（动态、好友、通知、日志、玩家管理等）在 VR 中切换为专用记录卡片。每批展示 12 条，滚动或点击“继续显示”追加下一批；原分页继续生效。卡片保留原单元格操作、行操作、右键菜单和展开详情；“排序与字段”提供原排序、批量选择与字段显示设置。刷新期间暂停卡片内操作，避免针对旧记录误操作。

## 手柄交互

- 扳机按下/松开对应真正的指针按下/松开，可拖动滑块和滚动条；快速连续点击保留双击语义。
- 摇杆/触控板支持纵向、横向滚动。使用顶部“右键”可在最后指向的位置打开上下文菜单。
- 顶部保留键盘、右键和关闭弹窗；点击“输入工具”展开全选、退格与回车。先指向输入框，再打开 SteamVR 键盘；密码框使用密码输入模式。中文等内容也可通过“粘贴”输入。
- 文件选择器提供快捷位置、上一级、路径输入、64 条分页和取消。浏览器原有文件输入会收到真实文件选择结果，继续走原上传逻辑。
- 不可访问的目录显示错误；取消或退出工作区会结束待处理的文件选择。

## 会话与显示

工作区使用主渲染器已有的账户、Store、API 和数据库上下文，不创建额外登录会话。VR 专用布局在该会话中渲染，再通过内部桥送给 SteamVR 的独立方形纹理；不是 Windows 桌面画面采集。

使用工作区期间，桌面主窗口也会显示这套 VR 布局。返回快捷控制、关闭 SteamVR 菜单或停止集成后，会恢复桌面布局和视口。VR 操作中更改的业务设置仍按原规则保存。

系统文件夹、外部链接、VRChat 和其他外部程序的启动仍由原宿主执行；工作区不会把其他软件的系统窗口转换为 VRCX 页面。Electron 的下载仍使用其原下载机制。

## 开发与验证

- `src/vr/workspace/`：VR 导航、路由目录、文件选择器、交互样式和坐标映射。
- `src/vr/components/WorkspacePanel.vue`：SteamVR 画布、输入转发、状态和连接续期。
- `src/services/vrWorkspace*.js`：主渲染器显示会话及文件选择桥。
- `Dotnet/Overlay/Cef/DashboardWorkspaceCapture.cs`：CEF 布局渲染、真实浏览器输入和文件选择接入。
- `Dotnet/Cef/VrWorkspaceDialogHandler.cs`：CEF 原生文件对话框接入，显式取消上传/保存；已有同名导出文件会保留并生成新名称。
- `src-electron/vrWorkspaceCapture.cjs`：Electron 对应桥接。

只在工作区打开时输出帧；关闭、断开连接或 15 秒未续期会停止。使用单次顺序采集和发送避免堆积。坐标依据 CSS 视口和实际图像留边映射，避免 DPI、缩放和顶部工具栏产生偏移。

验证覆盖目录入口、画布边缘、拖动/右键、滚动、账户切换保护、邀请启动方式、会话关闭、文件分页/取消/多选、CEF/Electron 能力契约。头显内的可读性、长列表与各类弹窗需结合实机反馈继续验收；自动化测试通过不等同于已逐项实测所有页面。
