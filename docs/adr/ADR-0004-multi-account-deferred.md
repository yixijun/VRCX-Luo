# ADR-0004：多账户会话与聚合实现暂缓

- 状态：Deferred
- 日期：2026-09-05
- 范围：B-02 数据隔离、M-05 会话与聚合视图

## 背景

多账户设计涉及 `dbVars` 热切换、账号会话生命周期、请求/好友缓存前缀、WebSocket 和聚合视图。当前设计草案与运行时代码仍存在契约漂移；在单账户宿主 capability、刷新链路和测试门禁尚未稳定前贸然实施，回滚面过大。

## 决策

按当前维护要求暂缓 B-02/M-05 的运行时实现。后续只有在重新确认数据库隔离、会话替换、聚合读取和失败恢复的 Interface 后，才恢复该任务。

## 约束

- 不以类型修复、文档整理或其他 Minor 任务为理由改写 `dbVars`、`accountHub`、二级 session registry 或聚合合并逻辑。
- 任何恢复工作必须先更新多账户详细设计和本 ADR，再建立小型 Seam 与隔离测试；不得与第三方升级或生成文件刷新混在同一提交。

## 重新评估条件

至少需要：单账户回归基线稳定、数据库上下文/前缀 Interface 明确、WebSocket 与缓存迁移策略可回滚、聚合视图输入输出契约有测试覆盖，并得到明确的恢复授权。
