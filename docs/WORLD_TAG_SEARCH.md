# 世界标签搜索

在“搜索 → 世界”中点击“世界标签”按钮展开筛选栏，在输入框中输入标签，回车或点击“按标签搜索”。也可点击社交、游戏、休闲、睡眠、模型、音乐快捷标签。再次点击“世界标签”收起筛选栏，已输入的标签会保留；按钮上的圆点表示标签输入不为空。

- 可以留空顶部关键词，只按标签搜索；也可以将名称关键词与标签一起查询。
- 普通标签自动补全 `author_tag_` 前缀，例如 `game` 会搜索 `author_tag_game`；也可粘贴完整标签。
- 多个标签可用中英文逗号、顿号或分号分隔，自动忽略空项并去重，匹配其中任意一个标签。
- 按标签搜索会退出当前分类；重新选择分类会清空自定义标签，避免分类标签与自定义标签含义混淆。
- 未勾选“包含位于社区实验室的世界”时，有标签的请求使用 `notag=system_labs` 排除实验室世界。无标签的普通搜索保留原来的已审核世界条件。
- 滚动追加结果沿用本次已提交的标签；仅编辑输入框不会改变正在追加的结果。清空输入框后再次搜索可取消标签条件，工具栏的清空结果按钮也会清空标签。

查询继续使用现有世界搜索 API，每页 10 条。切换标签后，旧请求即使稍后返回也不会覆盖新结果。

API 的 `tag` 参数是任意匹配，因此不能把 `system_approved` 作为额外的包含标签拼入，否则不符合目标标签的已审核世界也可能被返回。参见 [世界搜索查询参数](https://vrchat.community/reference/search-worlds)。
